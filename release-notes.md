X Bootstrapper 2.1.1 turns on Discord Rich Presence out of the box, with no setup needed.

## Changed
- **Discord Rich Presence works without setup.** X Bootstrapper now ships its own Discord application, "X BootStrapper For Octane". While a game you started through X Bootstrapper is open, your profile shows "Playing on Octane" with the Octane artwork and your play time
- If Discord isn't running when the game starts, presence appears once you open Discord (and comes back if Discord restarts)
- A custom Discord application ID is now optional. An empty field uses the built-in application, and any ID you already entered is kept
- Activity tracking still controls whether the place ID is shown

Existing installs update automatically from GitHub Releases. New users: download **X.Bootstrapper.Setup.exe**. No administrator account is required.
