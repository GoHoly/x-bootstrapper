X Bootstrapper 2.4.1 — skybox changer, 3D custom skies, Halloween, atmosphere mods, and candy clicks.

## Skybox changer
- **Skybox changer on Mods** — pick Default or a built-in sky (Sunset, Night, Nebula, Clear day, and more) from the sky row
- Each sky tile shows a **face preview** so you can see the look before you apply
- **Apply sticks on launch** — faces are re-copied while Octane starts so stock client files cannot silently win

## Custom skybox (3D)
- **Custom sky editor** — upload all six cube faces (front / back / left / right / up / down)
- **3D skybox preview** — drag to look around the sky sphere in the editor before you apply (how Octane’s default sky sees the faces)
- Save and apply your custom set from the Mods sky row (Custom tile)

## Halloween theme & candy
- **Halloween theme (default)** — charcoal UI, pumpkin-orange accents, dripping neon X logo
- **Theme logos on the taskbar / tray** — the window and tray icon follow whichever theme you pick
- **Candy click bursts** — candy corn, wrapped sweets, lollipops, and jelly beans in pumpkin orange (lighter sprinkle)

## Atmosphere mods & tooling
- **Atmosphere mods** — clouds, sun/moon, particles, water packs, indoor sky, and Replace client file
- **Mod previews** — thumbnails, Play for sounds, and particle-field previews
- **Mod presets** — built-in starters (Stock, Sunset / Night / Nebula / Clear day sky) plus save/load of your full Modifications set

## Also included
- Automatic renderer prefers Direct3D 11; unlimited FPS clears the 240 cap; WrittenFlagKeys save after apply
- Discord status shows the Octane place name, not only `Place {id}`
- App Beta launch path when the client supports `--app`

## Install
Download **X.Bootstrapper.Setup.exe** and run it (no admin). You still need Octane from [octane.wtf](https://octane.wtf) first.
